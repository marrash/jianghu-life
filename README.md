# 江湖一生 · 山河故人 v1.2

儲存庫：[marrash/jianghu-life](https://github.com/marrash/jianghu-life)。GitHub Pages 自動部署設定與日後同步方式見 [部署說明](docs/deployment.md)。

解壓縮整個 ZIP 後，直接開啟 `index.html`；Windows 也可雙擊 `開始遊戲.cmd`。無須安裝套件或登入，腳本與樣式已內嵌，不使用遠端字型、圖片或 API。

只想帶走一個檔案時，使用 `江湖一生_單檔版.html`（工作區名稱為 `江湖一生.html`）。這份檔案連 favicon 與頁首圖示也已內嵌，無須旁邊的 assets 資料夾。完整資料夾則提供分享封面、SVG／ICO／PNG 圖示與 manifest。

本次實際驗證入口為本機網站。若瀏覽器對直接開啟檔案的儲存／下載有限制，可在資料夾執行 `python -m http.server 8791 --bind 127.0.0.1`，再開啟 `http://127.0.0.1:8791/`。不要同時重複啟動已在使用的連接埠。

## 怎麼玩

建立姓名，選擇三種出身、三個門派與三條武學之一。十五章覆蓋十五至六十歲的重要階段，結局回顧至六十五歲。前五章一年一章，後面跳過平淡歲月。

每章三次行動，用完後面對人物事件。每次抉擇後會顯示結果，再繼續。五場重要比武皆為三回合，兩合得勢即勝；敗戰仍會繼續人生。

搶攻克試探、守勢克搶攻、試探克守勢。快劍搶攻、重劍守勢、掌法試探有額外加成；招牌武學消耗 18 內力。低健康影響比武，並不會突然結束人生。

武學等能力在 60／85 後成長遞減。50 歲後需留意健康衰退。盤纏可買藥、支援故人、投資商路；36 歲後可教導後輩。下山選定行俠／守護／師門志向，取得不同的行動加成。

## 存檔與接續

進度自動保存在目前瀏覽器。清除瀏覽器資料會清除進度；不同網址、連接埠、瀏覽器與離線檔的存檔不一定共用。

右上角「存檔」可下載 JSON，或複製畫面中的全部存檔文字備份。換裝置時選 JSON 檔或貼上文字，再按「載入並接續這份人生」。若下載受瀏覽器限制，可把存檔文字存為 `.json`。損壞或不支援的存檔會拒絕載入，保留原進度。

同網址的 v0.1 序章進度會自動升級。已完成五年大比的人物可以接續第六章；升級不刪除舊存檔。按「重啟人生」並確認後，才會清除目前與舊版人物進度，人生圖鑑會保留。

重現同一人生需要相同版本、命運種子、出身、門派、武學與選擇。v1.0 數值平衡已調整，因此舊版歷史保留，但後續結果使用新版規則。

## 本版內容

三個門派、三種出身、三條武學、十五章、五十二個事件節點、五場重要比武、八種人生結局。包含師父、師兄、勁敵與弟子關係、選擇記憶、傳承、盤纏、存檔管理、人生小傳與結局圖鑑。

這是可走完完整人生的單機版本；沒有多人、即時動作戰鬥或仙俠篇，尚未公開部署。

## 開發

`npm test`：核心規則與完整人生測試。`npm run build`：重建離線 HTML。無 npm 依賴。

`core.js`：序章事件與遊戲規則。`content.js`：新增章節、事件、門派與對手。`app.js`：畫面、存檔與圖鑑。`style.css`：桌面與手機樣式。

`docs/full-version-plan.md` 為本次範圍，`docs/verification-v1.md` 為實際驗證紀錄。原始序章打包保留於 `releases/江湖一生_序章_v0.1.zip`。

## v1.1 收尾

新增原創「青山、劍鋒、朱日」favicon 與一致的頁首識別；包含 SVG、ICO、16/32/48/180/192/512 PNG、1200×630 分享封面。

結局的「保存江湖小傳」可直接查看全文、選取複製或下載 TXT。存檔選單也提供完整 JSON 文字備份。

尚未有公開網站網址。分享封面已備妥；若日後部署，建置時設定 `JIANGHU_SITE_URL` 為網站目錄的完整網址（以斜線結尾），即可輸出絕對圖片網址。manifest 提供圖示與啟動資訊，不代表已完成 PWA 離線安裝。

開發打包：`npm run build` 後執行 `npm run package`。美術素材可用 `python scripts/brand-assets.py` 重建（開發端需 Pillow）；遊戲本身無 Python 或 Node 需求。
