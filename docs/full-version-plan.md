# 《江湖一生》完整生涯版 1.0

使用者已同意原先完整首版規畫並要求繼續完成。本次直接沿用三門派、三出身、40～60 事件、6～8 結局的已核准方向。

## 實際範圍

- 保留紙墨山景、文字抉擇與每章三行動。十五章覆蓋 15、16、17、18、19、22、25、28、32、36、40、45、50、55、60 歲，尾聲回顧至 65 歲。前五章一年一章，後期跳過平淡歲月，避免逐年重複操作。
- 三門派：青嵐（武學）、赤霞（體魄）、聽雨（內功）；三出身：寒門、商戶、流落；三武學：快劍、重劍、掌法。差異落在屬性、練功收益與專屬授業事件。
- 沿用十二序章事件，新增四十個下山、中年、傳承與晚年事件，共五十二節點。重要事件讀取師兄舊傷、渡口救人、顧寒敬意、師門、志向等記憶。
- 行俠、守護、掌門三志向在下山後選定；五次重要戰鬥有不同對手與勝敗後果，失敗繼續人生。
- 加入俠義、門派貢獻、弟子傳承與盤纏用途。高屬性成長遞減，晚年健康下降；休養、調息、交遊、工作仍有價值。
- 八種人生結局，以晚年選擇、關係、傳承、聲望與重要戰績判定；結局圖鑑、完整小傳、存檔匯出匯入。
- v0.1 本機存檔保留並可升級，已完成的五年結局可繼續下山。不部署外站、不加入多人或仙俠。
