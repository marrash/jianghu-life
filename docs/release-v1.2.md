新增四組已確認的命運種子祕碼。公開模式有啟用提示；兩組隱藏模式只留下入場敘事，不在開局表單及玩法說明公開列碼。

作弊狀態隨人物存檔保存，舊存檔不會因文字巧合而自動啟用。正常人生圖鑑與別卷人生分開保存、匯出與匯入。人物關係、事件門檻、俠義與結局條件仍由正常選擇決定。

22 項自動測試通過。驗證包含四組開局能力、精確字串匹配、資源與招式豁免、恢復規則、命運骰、必勝、完整十五章與中途讀檔，以及原版規則回歸。交付包含最新版單檔 HTML、資料夾版與 ZIP，保留 v1.1 ZIP。

本機 HTTP 實測四組開局：能力與盤纏正確，公開／隱藏提示分別呈現。透過存檔選單匯入程式產生的作弊結局測試存檔，確認正常圖鑑 0／8、別卷人生 1 種；測試使用独立連接埠 8793，未覆蓋使用者 8791 入口的進度。此次沒有人工重走四輪完整人生。

使用方式與離線檔案驗證限制延續 README.md；實測入口為本機 HTTP。
