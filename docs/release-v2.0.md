# v2.0 骰子江湖

每章擲出 3～6 顆修行骰，逐顆分配至五項能力。起始能力、潛力與骰點由種子決定；相同種子與操作可重現人生。分配可復原，刷新不能重骰。超過潛力後成本增加；健康低落會減少修行骰。

每章一場隨機際遇與一場人生關口，各至多三個選項。際遇顯示成功率、收益與風險，悟性、健康與累積特質會影響判定。十五章內五場比武，選一種策略後結算三合，逐合顯示骰點、實力與門檻。

四組既有祕碼改為所有骰點恆為六，不再提供高能力開局、資源豁免或必勝。兩組隱藏祕碼仍只留下入場敘事，結局與正常圖鑑分開。

舊存檔保留原規則並顯示提示。體驗新版請先匯出備份，再重啟人生；原圖鑑保留。

驗證涵蓋種子重現、分配復原、存檔往返、八種結局可達、全六並非必勝、情報收益及潛力成本。另以一千個普通種子模擬完整人生。瀏覽器實際點選完成十五章與五場比武，檢查刷新續玩及手機修行介面。這些是功能驗證，難度與趣味仍待玩家回饋。
