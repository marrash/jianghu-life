# 江湖一生・山河故人 v1.1 交付紀錄

本版為可從十五歲走到六十五歲結局的武俠單機遊戲。十五章、三種出身、三個門派、三條武學、五十二個事件節點、五場三回合比武、八種結局，包含人物關係、傳承、盤纏、自動存檔、JSON 匯入匯出、人生小傳與結局圖鑑。仙俠篇不在本版範圍。

## 開啟方式

解壓縮交付 ZIP，開啟 index.html，或在 Windows 雙擊「開始遊戲.cmd」。另附「江湖一生_單檔版.html」，腳本、樣式、頁首圖記與 favicon 全部內嵌。詳見 README.md 的存檔與本機網站操作說明。

## 本次完成

## 驗證界線

工具不允許開啟 file URL，故直接雙擊 HTML 的瀏覽器流程未實測；已驗證同一交付內容的 HTTP 流程與資產封裝。TXT/JSON 按鈕之外提供文字備份，不把下載按鈕觸發視為檔案落地成功。尚未公開部署，社群平台分享預覽未驗證；manifest 不代表已完成 PWA 離線安裝。
