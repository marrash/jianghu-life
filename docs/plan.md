# 《江湖一生》五年試玩版實作規畫

使用者已同意人物生涯養成方向，先交付拜師至第一次門派大比的完整小循環。本文將核准概念落成可執行範圍，於本次直接完成。

**目標：** 8～12 分鐘可走完五年，每年三次行動、兩個事件；第三與第五年加上因果事件，共十二個節點。兩種武學、三名固定人物、三回合大比、分歧結局與人生小傳。

**架構：** 無外部依賴的 HTML/CSS/JavaScript。`core.js` 管理狀態與規則；`app.js` 負責呈現及本機存檔；`style.css` 實作紙墨配色與山景；`build.cjs` 將來源合併為 `江湖一生.html`。本資料夾非 Git 倉庫，不建立倉庫。
