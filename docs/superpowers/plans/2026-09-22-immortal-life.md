# 命格、突破與渡劫實作計畫

使用者已確認：重大賭局有長期好壞後果、好壞命格影響機率、全六祕碼、延壽後能繼續遊玩。直接完成實作與公開部署。

**Goal:** 把十五章武俠人生接到有準備、風險與永久後果的修仙人生。

**Architecture:** 保留 v1–v3 存檔原玩法，新人物 v4。cultivation.js 共用骰子、修行與十五章事件；immortal.js 負責命格、重大關口、六章修仙生涯與結局。UI 由公開引擎 API 呈現機率、資格、代價與結果。

**Tech Stack:** 原生 JavaScript／HTML／CSS、Node test、GitHub Pages。

- [x] 寫新測試，確認缺少新 API 時失敗。
- [x] 命格 −2～+2，各骰面權重 12+命格×(2×骰面−7)，同種子固定。四祕碼固定六；顯示機率使用同一分布。
- [x] 洗髓、閉關、禁術救人、渡劫關口各三選：直接冒險、有成本的準備、保守退讓。缺少資格不可挑戰。永久傷勢、暫時恢復期與境界上限實際影響後續。
- [x] 60 歲比武後選凡人餘生或渡劫；成功延續 75／90／110／140／170／200 歲六章。最後飛升失敗可能身死，事前明示。修仙途中可退休，保留八個凡人結局，新增修仙結局。
- [x] UI 增加命格、境界、壽元、傷勢；關口顯示精確成功率與具體代價；年齡、行程、圖鑑及小傳改為依進度計算。
- [x] 新存檔嚴格驗證、種子重現、舊檔兼容、完整普通與祕碼生涯、多種成敗與結局路徑測試。
- [x] 程式碼審查、真實瀏覽器手機／桌面操作、build／tests／ZIP；打包完成；推送與公開部署另於交付時確認。

界線：無線上帳號／排行榜／付費；不強迫每局修仙，不讓壞命格無路可走，不宣称遊戲趣味已經由自動測試驗收。
