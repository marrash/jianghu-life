# 骰子人生 v2.0 實作計畫

使用者已確認：減少選項，參考棒球人生的骰子分配與隨機事件；祕碼改為骰六種子，不再直接灌滿能力與判勝。獨立實作，不複製參考作品程式或文案。

- 新建人物採 v3 存檔：隨機起始能力、各能力潛力與修行餘額。
- 十五章，每章先擲 3～6 顆修行骰（健康差減少），逐顆分配武學、內功、體魄、身法、悟性；可復原未確認的分配，確認後不得重骰。
- 每章一個隨機事件與一個人生關口。隨機池依年齡及狀態篩選，三種風險對應不同骰子成功門檻與得失；人生關口控制感情、志向及結局，不擲骰判定道德選擇。
- 特質依累積行為解鎖，影響骰點或判定；高能力與超潛力提高修行成本，餘點累積。
- 五場比武各選一次策略，自動結算三合，以能力與骰點判勝；敗戰繼續。
- 四祕碼僅固定所有命運骰為六，不固定抽卡、數量或潛力，不免成本、不保證勝利；保留公開/隱藏入場文字與別卷圖鑑。
- 舊 v1/v2 人物保持舊規則，不強制轉換；匯出/匯入與圖鑑繼續可用。

檔案：新增 cultivation.js 包裝既有 core API 與 legacy 遊戲；app.js 切換新舊畫面；build.cjs/index.html 載入新模組；style.css 加骰子配點版面；版本與封裝更新。

驗收：新規則測試（決定性、隨機差異、祕碼六點、非必勝、潜力蓄力、事件失敗、復原、各階段存檔與損壞拒絕、十五章與結局），保留舊規則回歸；瀏覽器實玩新開局、配點、事件、比武與存檔，手機檢查；發布後驗證 Pages。
