# v3.0 命格與仙途

命格由種子決定，分為多舛、薄運、平常、順遂與福澤。命格改變六個骰面的權重，影響修行、際遇、比武與突破。相同人物設定、種子與選擇可重現；不是只換一串隨機數而沒有長期運勢差異。

洗髓、築基、先天、禁術救人、首次渡劫、元嬰與九霄雷劫都有明確的資格、資源成本與成功／失敗代價。直接挑戰、花費丹藥護法、保守退讓至多三選。永久傷勢降低比武實力，累積後提高突破難度；恢復期影響後續修行骰，調養可縮短恢復期。洗髓失敗的潛力損失與禁術的壽元損耗不會被普通休息抹去。

十五章江湖仍可走到八種原有結局。首次渡劫成功後進入七十五至兩百歲、最多六章仙途。金丹壽元 180；元嬰壽元 260，可挑戰兩百歲天劫。新增長生歸客、九霄登仙、殞身天劫三種結局。登仙壽元 500 是結局設定，遊玩在兩百歲登仙時成卷，沒有承諾五百歲後續章節。

四組既有祕碼保持全六，包含重大關口；仍需達到資格、付出費用與救人的必付代價。普通圖鑑與別卷人生分開。舊人物 v1–v3 保留原規則，新人物使用 v4 存檔；先備份再重啟即可體驗新系統。

驗證包含舊版回歸、命格機率、重大關口成功與失敗、恢復期、永久潛力損失、資格鎖定、資源不足、全滿能力、壽元終點、最終天劫殞命／生還、種子重現及各階段存檔往返。主流程以 250 個普通種子逐步讀寫模擬，另有獨立審查抽樣；這是功能與機率一致性驗證，不代表趣味與難度已由玩家驗收。

瀏覽器實際由十五歲點選到兩百歲登仙，檢查關口重新整理續玩、能力上限、年齡、後續章節、小傳與手機排版。打包保留 favicon、資料夾版、單檔 HTML 與 ZIP。
